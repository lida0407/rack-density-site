## 您将获得

- **电力层：** UPS 负载、续航时间和电池电量显示在单线图上；PDU 和 IPMI 功率显示在设备上。点击 UPS，按 **Fail**（模拟故障），即可看到哪些机柜断电、哪些服务停止。
- **气流层：** 温度监控项变为机柜进风或排风读数；机房按温度自动着色，当某台制冷单元被设为故障时，会估算出“升至 27、32 和 35 °C 所需的分钟数”。
- **设备上的告警：** 未解决的 Zabbix 问题会作为告警显示在匹配的设备上，旁边就是该设备承载的工作负载和租户。

## 如何连接

1. 在 Zabbix 中为只读用户创建 API 令牌（或使用只读用户名和密码）。
2. 在 DC Sim 中打开 **⋯ → Connect NetBox or Zabbix**（连接 NetBox 或 Zabbix），选择 Zabbix，粘贴 URL 和令牌，按 **Test**（测试）。测试会显示 Zabbix 版本，以及它能看到的主机、监控项和未解决问题的数量。
3. **Preview**（预览）会显示有多少主机与数字孪生中的设备匹配，以及将要添加的读数和告警。
4. **Import**（导入）。每次同步都会添加最新读数和未解决的问题。

在您自己的网络内，同一个连接器运行在 DC Sim 代理程序中，该代理程序只主动向外连接。

## 我们读取的内容

| Zabbix | DC Sim | 图层 |
|---|---|---|
| 主机及主机资产信息（位置、机柜、型号、序列号） | 按名称与设备匹配 | 设备 |
| 电力监控项（PDU、UPS、IPMI） | `power_w` | 电力、Token |
| 进风或环境温度监控项 | `inlet_c` | 气流 |
| CPU 温度、风扇转速、湿度 | `cpu_temp_c`、`fan_rpm`、`humidity_pct` | 设备、气流 |
| UPS 续航时间、负载和电池监控项 | `ups_runtime_min`、`ups_load_pct`、`ups_battery_pct` | 电力 |
| CPU 利用率、ping | `util_pct`，在线或离线 | 设备、网络 |
| 未解决的问题 | 匹配设备上的告警 | 全部 |

## 另一种方式：表格导出

没有 API 访问权限？按主机导出近期的监控项数值，放入模板的 **Readings**（读数）工作表（`time`、`item`、`metric`、`value`），并把主机填入 **Devices**（设备）工作表。

## 无需入站连接

对于部署在您网络内的 Zabbix，连接器运行在一个小型代理程序中，它只通过一条 WebSocket 主动向外连接，从不监听任何端口。如果连接中断，数据批次会缓存到磁盘，并按顺序重放。令牌保存在代理程序的配置中；DC Sim 只接收数值和问题。
