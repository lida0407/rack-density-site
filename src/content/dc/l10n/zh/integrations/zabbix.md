## 主要能力

- **供配电图层（Power）：** UPS 负载、后备时间与电池电量显示在配电单线图上；PDU 与 IPMI 功率显示在对应设备上。选中 UPS，点击 **Fail**（模拟故障），即可查看哪些机柜失电、哪些业务中断。
- **气流图层（Air）：** 温度监控项转为机柜进风或排风温度监测数据，机房按温度着色；将某台精密空调设为故障时，系统估算温度升至 27、32、35 °C 所需的分钟数。
- **告警定位到设备：** Zabbix 未处理告警显示在匹配的设备上，与该设备承载的业务负载及租户信息并列呈现。

## 对接步骤

1. 在 Zabbix 中为只读用户创建 API 令牌（也可使用只读用户名与密码）。
2. 在 DC Sim 中打开 **⋯ → Connect NetBox or Zabbix**（对接 NetBox 或 Zabbix），选择 Zabbix，填入 URL 与令牌，点击 **Test**（测试连接）。测试结果显示 Zabbix 版本，以及可读取的主机、监控项与未处理告警数量。
3. **Preview**（预览）显示与数字孪生设备匹配的主机数量，以及将新增的监测数据与告警。
4. **Import**（导入）。每次同步均加入最新监测数据与未处理告警。

Zabbix 部署在内网时，同一对接功能运行于 DC Sim 采集代理（Agent）中，该代理仅发起出站连接。

## 读取的数据

| Zabbix | DC Sim | 图层 |
|---|---|---|
| 主机及主机资产信息（位置、机柜、型号、序列号） | 按名称与设备匹配 | 设备 |
| 功率监控项（PDU、UPS、IPMI） | `power_w` | 供配电、Token |
| 进风或环境温度监控项 | `inlet_c` | 气流 |
| CPU 温度、风扇转速、湿度 | `cpu_temp_c`、`fan_rpm`、`humidity_pct` | 设备、气流 |
| UPS 后备时间、负载与电池监控项 | `ups_runtime_min`、`ups_load_pct`、`ups_battery_pct` | 供配电 |
| CPU 利用率、ping | `util_pct`，在线或离线 | 设备、网络 |
| 未处理告警 | 匹配设备上的告警 | 全部图层 |

## 替代方式：表格导出

如无 API 访问权限，可按主机导出近期监控项数值，填入导入模板的 **Readings**（监测数据）工作表（`time`、`item`、`metric`、`value`），并将主机填入 **Devices**（设备）工作表。

## 无需入站连接

对于部署在内网的 Zabbix，对接功能运行于轻量级采集代理中。采集代理通过一条 WebSocket 连接主动出站，不监听任何端口。链路中断时，数据批次缓存至本地磁盘，恢复后按顺序补传。令牌仅保存在采集代理配置中；DC Sim 只接收监控数值与告警。
