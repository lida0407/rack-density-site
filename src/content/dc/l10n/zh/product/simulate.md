## 两种速度的故障推演

**Fail**（即时推演）。在配电单线图、网络拓扑或 3D 机房中点击任意节点，再点击 Fail（模拟故障）。服务器端执行图传播计算：供电故障使相关设备失电，网络拓扑同步移除这些设备，图示、3D 视图（机柜着色、设备颜色、失效线缆）与横幅提示同时显示结果，例如“Fail UPS-A — 2 devices lose power · 90 run on one feed · overloaded: PDU-R05-B 113.9%”（UPS-A 故障：2 台设备失电 · 90 台单路运行 · 过载：PDU-R05-B 113.9%）。

**Simulate it**（时间线推演）。同一故障经完整仿真器运行（电池后备时间、发电机启动、断路器脱扣曲线、热瞬态、token 损失），按分钟推进，并与基线并列对比。估算值均有标注。

## 场景库

| 场景 | 回答的问题 | 涉及图层 |
|---|---|---|
| 市电中断 | 发电机能否及时启动；当前负载下的电池后备时间 | 供配电 |
| 发电机启动失败 | 哪些机柜依靠电池维持运行，可维持多久（估算） | 供配电 |
| 峰值负载时失去 A 路 | 哪些设备失电，哪些依靠 B 路维持，哪台 PDU 过载 | 供配电、网络、Token |
| UPS 模块故障 | 失去供电的单电源设备，中断的服务 | 供配电 |
| 制冷单元或冷水机组故障 | 各机柜升至 27、32、35 °C 所需的分钟数（估算） | 气流 |
| CDU 故障或分集水器漏液 | 泄漏量（升，估算）、隔离阀动作、被隔离的机柜 | 水系统 |
| 分区火灾 | 探测、报警、暖通联动、灭火剂释放、EPO；分区内的机柜与服务 | 消防、供配电 |
| 负载增加 25 % | 哪些断路器、制冷单元和机柜超过 80 %；容量可用时长 | 供配电、气流、平面 |
| 自定义 | 令任意节点故障、切断任意线缆、停止任意制冷单元 | 全部 |

涉及 GPU 节点时，每次运行均报告 **token 损失**。

## 回放与报告

**回放**：本周紧急与重要告警标注在时间滑块上。可定位到具体分钟，查看机房当时的状态，并导出事件日志。

**报告**：能耗、PUE、CO₂ 与成本；按业务、租户、模型和服务器统计的 token；每千瓦时 token 数；容量可用时长；热环境；事件；维保到期。估算值均有标注。

## 零成本演练

A 路断电演练应在维护窗口之前完成，而不是在窗口期间进行。签约之前即可向客户展示审计结果。故障复盘时以事件回放替代白板草图。

以往，UPS 故障影响分析需要聘请顾问、耗时一周。在 DC Sim 中，流程为：令 UPS 故障，查看失电设备清单，整改单电源设备，再次运行。操作步骤详见：[20 分钟完成 UPS 故障影响分析](/resources/guides/ups-failure-impact-analysis/)。
