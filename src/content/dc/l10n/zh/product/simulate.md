## 两种速度的假设推演

**Fail**（即时）。在配电单线图、网络拓扑或 3D 机房中点击任意节点，按 Fail（模拟故障）。服务器端运行一次图传播计算：电力故障让设备断电，网络图随之失去这些设备，图示、3D 视图（机柜着色、设备颜色、失效线缆）和横幅提示同时显示结果，例如“Fail UPS-A — 2 devices lose power · 90 run on one feed · overloaded: PDU-R05-B 113.9%”（UPS-A 故障：2 台设备断电 · 90 台靠单路运行 · 过载：PDU-R05-B 113.9%）。

**Simulate it**（时间线）。同一次故障通过完整的仿真器运行（电池后备时间、发电机启动、断路器曲线、热瞬态、token 损失），逐分钟推进，并与基线并排对比。估算值均有标注。

## 场景库

| 场景 | 回答什么问题 | 图层 |
|---|---|---|
| 市电中断 | 发电机能否及时启动；当前负载下的电池后备时间 | 电力 |
| 发电机启动失败 | 哪些机柜在靠电池续命，还能撑多久（估算） | 电力 |
| 峰值时失去 A 路供电 | 谁断电，谁靠 B 路维持，哪台 PDU 过载 | 电力、网络、Token |
| UPS 模块故障 | 失去供电的单电源线设备，中断的服务 | 电力 |
| 制冷单元或冷水机组故障 | 每个机柜升至 27、32、35 °C 所需的分钟数（估算） | 气流 |
| CDU 故障或分集水器漏液 | 泄漏量（升，估算）、隔离阀、被隔离的机柜 | 水冷 |
| 某个分区发生火灾 | 探测、报警、暖通空调联动、灭火剂释放、EPO；分区内的机柜和服务 | 消防、电力 |
| 负载增加 25% | 哪些断路器、制冷单元和机柜超过 80%；容量可用时长 | 电力、气流、平面 |
| 自定义 | 让任意节点故障、切断任意线缆、停掉任意制冷单元 | 全部 |

凡涉及 GPU 节点，每次运行都会报告 **token 损失**。

## 回放与报告

**回放**：本周的紧急和重要告警显示在时间滑块上。拖动到具体某一分钟，查看机房当时的状态，导出事件日志。

**报告**：能耗、PUE、CO₂ 和成本；按业务、租户、模型和服务器统计的 token；每千瓦时 token 数；容量可用时长；热状况；事件；维保到期。估算值均有标注。

## 零成本演练

在维护窗口之前做 A 路断电演练，而不是在维护窗口期间。签合同之前，先把审计结果给客户看。故障复盘时放事件回放，而不是在白板上画草图。

过去，UPS 故障影响分析意味着请一位顾问、花上一周时间。在这里只需：让 UPS 故障，查看失电设备清单，整改单电源线设备，再运行一遍。分步指南：[20 分钟完成 UPS 故障影响分析](/resources/guides/ups-failure-impact-analysis/)。
