## 客户关心的问题

“开工之前，先让我看到机房。”“UPS 故障会造成什么影响？”“这根线缆接到哪里？”“哪台 GPU 服务器的产出与其能耗相称？”数字孪生可在首次会议中回答这四个问题，而多数方案仍以平面图和电子表格作答。

## 合作伙伴权益

| | |
|---|---|
| **收入分成** | 您带来的设计版授权与监测版订阅，在客户持续使用期间均可获得 30 % 的利润分成；承诺业务量的合作伙伴也可选择缴纳年度合作伙伴费，获得更高利润率。具体条款以合作伙伴协议为准。 |
| **演示机房** | 可直接用于演示的成品机房：一个边缘机房、一个含液冷 GPU 机柜列的 96 柜机房，以及基于 Excel 导入模板搭建的演示机房。我方会在会议中导入您客户提供的文件。 |
| **方案用设计版授权** | 每个在跟项目可按合作伙伴价格获得一份设计版授权，使数字孪生在客户付款前即可纳入方案。 |

## 适用对象

- **系统集成商与数据中心建设商**：设计并建设 5–200 个机柜规模的机房。
- **托管服务商（MSP）**：为客户运营服务器机房、边缘站点与托管笼位；将监测版作为“机房状态可视”服务层对外销售。
- **机电咨询顾问**：需要面向中小型机房、如实标注且并非 CFD 的场景推演工具。
- **机房托管与主机托管售前团队**：基于潜在客户自己的设备清单，展示其未来的托管笼位。
- **技术合作伙伴**：监控与 DCIM 软件厂商，DC Sim 读取其数据，其客户需要机房视图。→ [集成](/integrations/)及技术合作伙伴一页简介。

## 合作流程

1. **申请**：通过电子邮件提交（见下文）。我们将在两个工作日内回复，提供协议与价目表，并安排一次演示。
2. **培训**：完成两次培训后，即可使用演示机房开展演示。
3. **提案**：每个项目按合作伙伴价格获取一份设计版授权；客户的 Excel 文件即成为方案中的数字孪生。
4. **移交**：客户上线监测版；您保留分成与客户关系。

## 技术合作伙伴

如果您提供监控或 DCIM 软件，DC Sim 是构建在您数据之上的机房视图与场景推演，而非替代您的产品。首批对接为 Zabbix 与 NetBox；每项对接均先在演示实例上完成测试，方标注为“已可用”。读取哪些数据、计划回写哪些数据、对合作伙伴有哪些要求，详见[技术合作伙伴一页简介（PDF）](/downloads/dcsim-technology-partners.pdf)。
