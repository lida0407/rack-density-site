## 用客户的话说

“动工之前，先让我看看这个机房。”“UPS 故障了会怎样？”“这根线缆通到哪里？”“哪台 GPU 服务器真正对得起它的耗电？”数字孪生在第一次会议上就能回答这四个问题。而大多数方案书仍然只用一张平面图和一份电子表格来回答。

## 合作伙伴可获得

| | |
|---|---|
| **收入分成** | 您带来的 Design 许可证和 Monitor 订阅，只要客户一直在用，您就持续获得 30% 的利润分成；或者，承诺销量的合作伙伴可选择支付年度合作伙伴费，换取更高的利润率。具体条款见合作伙伴协议。 |
| **演示机房** | 可直接用于演示的现成机房：一个边缘机房、一个带液冷 GPU 机柜列的 96 柜机房，以及用 Excel 模板搭建的演示机房。我们会在会议中导入您客户自己的文件。 |
| **用于方案书的 Design 许可证** | 每个跟进中的项目可按合作伙伴价格获得一个 Design 许可证，让数字孪生在客户付款之前就出现在方案书中。 |
| **贴牌** | 产品目前已可用品牌切换（已有两个版本）。依据合作伙伴协议，可按需提供合作伙伴品牌版本。 |

| **联合营销** | 本站上的集成页面和案例研究页面、联合网络研讨会、在您所在地区的销售线索转介。 |

## 适合谁

- **系统集成商和数据中心建设方**：设计和建设 5–200 个机柜的机房。
- **MSP（托管服务商）**：为客户运营服务器机房、边缘站点和托管笼位；把 Monitor 作为“我们看得见您的机房”这一层服务来销售。
- **机电顾问**：需要一套诚实、明确标注、非 CFD 的假设推演，用于中小型机房。
- **机房托管与主机托管售前**：用潜在客户自己的设备清单，向他们展示未来的笼位。
- **技术合作伙伴**：我们读取其数据、其客户也希望看到机房视图的监控和 DCIM 厂商。→ [集成](/integrations/)以及技术合作伙伴一页简介。

## 合作流程

1. **申请**：通过电子邮件申请（见下文）。我们会在两个工作日内回复，附上协议和价目表，并安排一次演示。
2. **培训**：完成两次培训后，您即可使用演示机房进行演示。
3. **提案**：每个项目按合作伙伴价格获取一个 Design 许可证；客户的 Excel 文件就变成方案书中的数字孪生。
4. **移交**：客户正式上线 Monitor；您保留分成和客户关系。

## 技术合作伙伴

如果您开发监控或 DCIM 软件，DC Sim 是构建在您的数据之上的机房视图和假设推演，而不是要取代您的产品。Zabbix 和 NetBox 率先支持；每个连接器都会先在演示实例上测试，之后我们才称其为“已可用”。我们读取什么、计划回写什么、对合作伙伴有什么要求，请见[技术合作伙伴一页简介（PDF）](/downloads/dcsim-technology-partners.pdf)。
