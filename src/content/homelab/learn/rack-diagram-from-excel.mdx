## What the diagram needs

A rack elevation is a lookup: for every U slot in every rack, which device covers it? The template's Devices sheet already has the columns for it:

| Column | Header | Example | Notes |
|---|---|---|---|
| A | rack | R01 | The rack's name, spelled the same in every row |
| B | u | 12 | The **lowest** U the device occupies |
| C | model | (any) | {PRODUCT_NAME} takes the height and the watts from the model |
| D | name | pve-01 | What you want to see in the slot |
| F | height_u | 2 | How many U it takes: a 2U server in U12 occupies U12 and U13 |

Leave `u` empty for gear that isn't in the rack (an access point, the ISP box): it stays in the list without taking a slot. For the formulas below, add one helper column L with the height, 1U when `height_u` is empty:

```
L2:  =IF(F2="",1,F2)
```

Download it here: [the free template (.xlsx)](/downloads/homelab-template.xlsx). It is the same file {PRODUCT_NAME} imports.

## Draw the rack with one formula

Make a second sheet, Rack view. Put the U numbers down column A from the top (for a 24U rack: 24 in A2, 23 in A3, down to 1 in A25) and the rack names across row 1 (B1 = R01, C1 = R02). Then, in B2:

```
=IFERROR(INDEX(FILTER(Devices!$D$2:$D$200,
   (Devices!$A$2:$A$200=B$1)
   *(Devices!$B$2:$B$200<>"")
   *(Devices!$B$2:$B$200<=$A2)
   *(Devices!$B$2:$B$200+Devices!$L$2:$L$200-1>=$A2)), 1), "")
```

Copy it across the grid. Each cell shows the device whose span covers that U in that rack, or stays empty. FILTER works in Excel 365, Excel 2021 and Google Sheets.

To make it look like a rack, add a conditional-formatting rule on the grid: format cells that are **not empty** with a fill colour. A 2U device then shows as a two-row block with its name in both rows.

## Find the clashes

Two devices in the same U is the most common mistake in a hand-made rack sheet. In the Devices sheet, column M:

```
=IF(B2="","",SUMPRODUCT((A$2:A$200=A2)*(B$2:B$200<>"")
   *(B$2:B$200<=B2+L2-1)
   *(B$2:B$200+L$2:L$200-1>=B2))-1)
```

It counts the other devices in the same rack whose span overlaps this one and skips off-rack gear. Anything above 0 is a clash: filter the column for values greater than 0.

## Keep it useful

- **One sheet, one truth.** Rename racks in one place; a typo in the rack column makes a device vanish from the grid.
- **Add the power.** A watts column next to each device turns the same sheet into a power budget: sum it per rack and compare it with your UPS and power-strip ratings.
- **Add the ports.** A Cables sheet (from device, from port, to device, to port) is what you need when a link goes down at 2 a.m.
